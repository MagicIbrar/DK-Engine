# DK Engine

DK Engine runs Dekaron Global as a one-click engine: a dashboard that hosts or joins a world, and a game
window that plays through it. It reads the game files from your own unmodified Dekaron Global install; no
game files are included here.

This repository is where the engine lives now, maintained by Magic Ibrar and the Magic Dekaron team, so it
stays available and keeps getting updates. The engine was created by one developer whose work on it is
extraordinary: a complete server and client rebuilt in a few months, with the care of a studio. That
developer prefers not to be named for now; the credit for everything here is theirs.

## Downloads

Each release has two packages:

- **Dashboard + Client (Host and Join)**: the full engine. Open `Client.exe` to host your own world or join one.
- **Join Only Client**: `GameWindow.exe` only, for players who join a hosted world. It is the `join-only-client`
  folder of this repository.

Start with `START-HERE.txt`, then `docs/UPDATE-4.2.0.md`, `docs/README.md`, `docs/SQL-SETUP.md` and `docs/HOSTING.md`.
