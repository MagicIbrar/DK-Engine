Setup Guide

  1. Dependencies are automatic. The complete engine release includes Three.js. If Node.js is missing, the launcher downloads and verifies a private runtime from nodejs.org without changing system settings.
  2. Supply your own compatible game client. Place the complete engine tool folder beside its data and bin folders. This download replaces only the launcher inside engine; it does not contain the engine or original game files.
  3. Open engine\Client.exe. Review the exact game folder and removal list, then click Install & Play once. After preparation succeeds it permanently removes the listed root extras, retaining data, bin, engine and Client.exe. There is no backup or second confirmation. Sign Up inside the launcher creates your account without cleanup. Later launches use Start.
  4. Let preparation finish. Supported packs are unpacked and indexed automatically before cleanup or play. First preparation can take several minutes and about 9 GiB of additional space. Later launches check your local files for updates. No separate unpacker is required.
  5. Log in. Enter the account ID and password you registered in the launcher. Website Sign Up creates the same kind of account. Unregistered accounts cannot log in.
  6. Create a character and play. Account progress is saved on this private host and returns when you sign in to the same server. A registered account is required; existing signed-in website sessions can be restored automatically.

Troubleshooting

⚠

Nothing opens

Keep the complete engine release together and use Windows PowerShell. Internet access is needed only when a missing private runtime must be downloaded. Open Client.exe from your normal Windows account.

🔒

Preparation stopped

Read the error in the client window. Incomplete or unsupported source files stop installation before cleanup. Keep the original files and finish copying an update before trying again.

🌐

Port already in use

The launcher reuses a matching engine server. An older data generation needs a restart; unrelated programs using the port are left alone.
