Find your world

Choose a server

Use the address shared by your host or refresh a public directory. Only worlds whose hosts choose to publish appear in that directory. Listed password-protected worlds still require their server password. An empty list does not mean a private world is offline.

Connect and create an account

Internet servers need HTTPS. A private world asks for its server password first, then offers Sign in and Create account. These are separate passwords. Check the server name and address before entering either one. Accounts and characters belong to that server; another world has separate accounts.

Return to server choice

Log out saves your progress, leaves the world and signs out before opening the server menu. If saving fails, stay in the game and retry. Character select keeps your account signed in on the same server. The login screen's Server and Exit buttons return to the server menu.

Host your own world

Open your installed Client.exe and choose its Host panel. A website can show setup options, but cannot start that program on your computer. See hosting options for the launcher and provider setup.

Cannot reach a world?

Ask the host to check that the server and its HTTPS relay are running. A temporary test address can expire. Server content, rates and saved progress come from the chosen host. The connector website supplies the menu; it cannot replace a running game server.
